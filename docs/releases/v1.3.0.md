# MokaSkill v1.3.0

## 主要更新

- 新增集成式 Interactive BOM：使用 `moka_ibom` 导出离线 HTML，使用 `moka_ibom_config` 设置显示层、焊盘、丝印、深色模式、BOM 布局、复选列、网络和走线数据等选项。
- Interactive BOM 可从 Moka Skill 菜单或 `mokaskill` 主面板打开，导出文件写入当前工程的 `ibom` 目录，不需要 Python、外部 InteractiveHtmlBom 安装或中间 JSON 文件。
- 修正 Anti-Pad 全板差分过孔批量处理、圆形过孔外扩计算和批量操作后的切层交互。
- 修正图标搜索路径处理，避免覆盖 Allegro 原生工具栏图标；英文菜单中的 Interactive BOM 项为 `Interactive BOM...`。
- 安装器更新为 v1.3.0，支持中文/英文菜单选择和卸载。

## 上游组件与许可证

Interactive BOM 的 HTML 查看器和界面资源采用上游开源项目 **InteractiveHtmlBom v2.12.0**，并保留其许可证与归属信息。Allegro 数据采集器基于上游 `juulsA/exportJson` 项目，安装包内同时包含对应许可证文件。

## 验证说明

SKILL 配置、Interactive BOM 配置/采集/导出按钮、Anti-Pad 和 PCB 标识语法测试已通过。浏览器自动化测试需要额外安装 Node.js `playwright`；Allegro 16.6/17.4 的实际 PCB 板验证仍建议在目标环境中完成。
