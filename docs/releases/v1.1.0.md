# MokaSkill v1.1

Anti-Pad 工具新增全层放置选项，已完成用户板级测试。

- “放置层”新增 `All`，在 `ROUTE KEEPOUT/ALL` 创建对所有走线层生效的 Keepout，保留单层放置方式。
- 选择 `All` 时，Via/Pin 轮廓取自开始选择时的活动 ETCH 层；没有活动 ETCH 层时取叠层中的首个 ETCH 层。同次操作固定参考层，不逐层合并不同 Padstack 轮廓。
- 功能面板与安装程序统一更新为 v1.1。
- README 补全全部功能命令、短别名和默认快捷键。

安装文件：`MokaSkill_Setup_v1.1.exe`。安装后重启 Allegro，在 Anti-Pad 的“放置层”中选择 `All` 使用。

验证：Anti-Pad 放置层回归检查 24 项通过，安装配置助手自检通过，Inno Setup 编译通过，用户板级测试通过。
