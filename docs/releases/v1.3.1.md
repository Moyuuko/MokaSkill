# MokaSkill v1.3.1

## 主要更新

- 层设置新增独立 `DRC ALL` 选项，对应 Allegro 的 `DRC ERROR CLASS/ALL`。
- `DRC ALL` 与各 ETCH 层的 DRC 选项互不联动，可单独显示等长、相位及其他全局约束 DRC。
- 旧配置升级后默认启用 `DRC ALL`；配置保存新增 `drc_all` 字段。
- 版本更新为 v1.3.1，安装器和安装说明同步更新。

## 验证

- Allegro SKILL 解释器下的 DRC ALL 可见性回归测试通过。
- 安装器配置自检通过，已生成 `MokaSkill_Setup_v1.3.1.exe`。

Interactive BOM 继续采用上游开源项目 **InteractiveHtmlBom v2.12.0** 的 HTML 查看器和界面资源；Allegro 数据采集器基于 **juulsA/exportJson**。对应许可证随安装包和源码保留。
