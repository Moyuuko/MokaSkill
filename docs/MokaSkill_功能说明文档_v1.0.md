# MokaSkill 功能说明文档

版本：`v1.0`

## 1. 简介

MokaSkill 是一套面向 Cadence Allegro 的 SKILL 工具集，当前主要包含八大部分：

1. `Moka` 主工具
2. `Align` 对齐工具
3. `Pin Swap` 工具
4. `Anti-Pad` 工具
5. `叠层 / 阻抗` 叠层阻抗工具
6. `走线等间距` 工具
7. `Copper Corner` 覆铜统一倒角 / 圆角工具
8. `Allegro` 工程日志清理工具
9. `Mooretronics Symbols` PCB 标识放置工具


## 2. 安装结果

自动修改 `pcbenv/env` 与 `pcbenv/allegro.ilinit`，用于：

1. 加载菜单
2. 注册命令别名
3. 注册功能快捷键

发行包使用基于开源 Inno Setup 的现代化 Windows 安装向导，会在 Windows“已安装的应用”和开始菜单中注册卸载入口。安装和卸载只管理带明确标记的 Moka Skill 配置块，不覆盖用户的其他 Allegro 配置。

安装程序提供 `MokaSkill 菜单栏语言` 选项：

1. `中文（默认）`：安装中文菜单加载器。
2. `English`：仅将 MokaSkill 菜单栏切换为英文，各功能界面仍使用中文；适用于中文菜单显示乱码的系统。
3. 切换语言时可直接重新运行安装程序，选择所需语言后安装，并重新启动 Allegro。

所有 Allegro SKILL 模块均以明文 `.il` 源码安装，不再生成或发布加密 `.ile` 文件。


## 3. 功能结构

### 3.1 Moka 主工具

Moka 主工具包含以下能力：

1. 走线层快速切换
2. 单层 / 多层显示模式切换
3. Move / Add Connect 命令下的模式切换
4. 过孔类型循环切换
5. 当前走线宽度快速修改
6. 层显示矩阵配置面板
7. PCB 设计状态统计
8. Trace Analyzer 走线分析工具
9. 换 Pin 工具入口
10. Anti-Pad 工具入口
11. 叠层 / 阻抗表格导入导出、模板替换和快速阻抗设置

### 3.6 Copper Corner 覆铜工具

`Moka skill -> 覆铜工具...` 用于修改已选覆铜边界：

1. `Uniform chamfer (modify / add)`：已有短斜边先恢复到虚拟尖角并统一倒角；没有倒角的角自动新增。
2. `Uniform round (modify / add)`：已有短斜边先恢复，再统一生成圆角；没有倒角的角自动新增圆角。
3. `Normalize existing only`：只统一已有倒角，不新增缺失倒角。
4. `Corner selection` 支持外角、内角和外角 + 内角三种范围。
5. 动态覆铜生成的 ETCH 子图形会自动提升到可编辑的 BOUNDARY shape。
6. 统一尺寸无法同时容纳全部目标角时整块跳过，不产生部分修改。
7. `修改单个角点`：连续点选覆铜角点，每次只修改当前角，其他角保持不变；右键 `Done` 提交本次全部修改，右键 `Cancel session` 回滚本次会话。
8. `一键覆铜`：按 `Shift+D`（或执行 `moka_quick_copper`），在当前活动 ETCH 层选择矩形两个对角点；工具会在匹配的 `BOUNDARY` 子层创建动态铜皮并立即更新填充，同时以矩形短边的 10% 自动计算四个外角的倒角尺寸。该功能不占用菜单栏入口，取消或失败时不会留下未完成铜皮。

### 3.7 Allegro 工程日志清理

`Moka skill -> Clean Project Logs...` 或命令 `moka_clean_logs` 会使用独立的 Allegro SKILL 模块递归扫描当前工程目录。它只删除文件名以 `.log` 或 `,数字` 结尾的文件，执行前会列出匹配项并要求确认；不会调用外部 PowerShell 脚本。

### 3.8 Mooretronics Symbols PCB 标识工具

`Moka skill -> PCB 标识...` 打开 26 个 Mooretronics PCB 标识图标面板。模块已并入 MokaSkill 安装程序，运行时从 `mooretronics-symbols` 资源子目录加载字形数据和图标 BMP，不再需要单独运行插件安装脚本。

1. `moka_symbols`：打开 PCB 标识面板。
2. `moka_symbols_place`：按当前面板设置进入连续放置。
3. `msymbols` / `mplace`：对应的 MokaSkill 命令别名。
4. 旧命令 `mts_symbols`、`mts_place` 和 `mooretronics_symbols` 继续兼容。

### 3.2 Align 对齐工具

Align 工具包含以下能力：

1. 左对齐
2. 右对齐
3. 上对齐
4. 下对齐
5. 水平居中
6. 垂直居中
7. 水平分布
8. 垂直分布
9. 智能对齐
10. 对齐到栅格
11. 对齐工具面板

### 3.3 换 Pin 工具

换 Pin 工具包含以下能力：

1. 在同一器件内交互式选择两个 Pin 并强制交换网络
2. 换Pin时保留原有连接走线，便于后续检查和调整
3. 常驻式操作面板与换前 / 换后日志
4. 导出器件实际物理引脚布局 Pinmap
5. 从物理 Pinmap 表格批量换 Pin
6. 可选将 PCB 网络颜色导出为 Pinmap 单元格背景色

### 3.4 Anti-Pad 工具

Anti-Pad 工具包含以下能力：

1. 在指定层创建反焊盘
2. 支持 Via、Pin、器件 Pin、Cline、Cline Seg、Shape、组件与 Group 等常用目标
3. 支持单对象、自动差分对、手动双对象和整体包围四种目标模式
4. 支持现有 Padstack `ANTI` 轮廓、原始轮廓、圆形、椭圆形和矩形
5. 支持外扩量、固定大小、最小直径和自动差分配对最大距离设置
6. 支持预览确认、连续处理、右键 `Oops`、整次取消回滚
7. 使用用户属性绑定来源对象与 Keepout，可重复替换或按对象删除旧设置

### 3.5 走线等间距工具

走线等间距工具用于对已布好的平行走线做无避障等距展开：

1. 不选择 Pin/Via，只选择每根走线中需要移动的一段直线 Cline Seg
2. 自动把投影位置最外侧的两根线作为固定边界
3. 将中间走线按中心线等间距重新分布
4. 不检查 DRC、铜皮、器件或其他走线冲突
5. 同步修剪或延伸两侧相邻直线，保证几何连接连续
6. 相邻段方向保持不变，因此移动前后的折角角度保持一致

## 6. Moka 主工具说明

### 6.1 走线层切换

1. `moka_prev` 切换到上一可用走线层
2. `moka_next` 切换到下一可用走线层

该功能基于当前板层结构工作，只在 ETCH 层之间循环。

### 6.2 单层 / 多层显示切换

`moka_all` 用于在单层显示与多层显示之间切换。

### 6.3 模式切换

`moka_mode` 根据当前正在执行的 Allegro 命令自动决定切换对象：

1. 在 `move` 命令下，切换抓取模式
2. 在 `add connect` 命令下，切换走线模式

### 6.4 过孔切换

`moka_via` 用于循环切换当前走线使用的过孔类型。

适合布线过程中快速切换不同 Via Padstack。

### 6.5 线宽修改

`moka_width` 会弹出输入提示，输入新的线宽后，尝试写入 Allegro 当前布线表单。

适合在交互式布线过程中快速改线宽。

### 6.6 Moka 主面板

`mokaskill` 用于打开主面板。

主面板主要用于：

1. 管理层显示矩阵
2. C1/C2 每行分别在下拉框前显示 `Class` 与 `Subclass` 标签；Class 自动枚举当前设计的有效类别，Subclass 随 Class 联动刷新并保留层颜色块，无需手动填写
3. 保存当前显示配置到 `moka_config.ini`；层叠增删或调整后，TOP、BOTTOM以及仍存在的同名层会继续保留原显示设置
4. `Bound` 右侧的 `Anti Etch` 列用于控制与当前 ETCH 层同名的 `ANTI ETCH/<layer>` 可见性，`ALL` 行可批量切换
5. 从主面板直接打开 Trace Analyzer
6. 从主面板直接打开换 Pin
7. 从主面板直接打开 Anti-Pad 工具
8. 从主面板直接打开位号工具

### 6.7 位号工具

在“层设置”面板点击 `位号工具`，或输入 `moka_refdes` 打开。工具以 MiniStatus 形式嵌入 Allegro 右侧 `Options` 控制栏，并使用适合窄栏的纵向布局，不再显示独立状态输入框；操作结果写入 Allegro 命令日志。

进入工具后会立即隐藏铜层并显示顶层丝印视图，Find Filter 会临时限制为 `Components`、`Symbols`、`Text`、`Lines` 和 `Other Segs`，关闭工具时恢复原来的选择过滤设置。在画布中可以直接选择器件，也可以点击丝印位号文字或属于器件封装的丝印线段，工具会自动追溯到对应器件。点击面板中的 `关闭` 或右键 `Done/Cancel` 可退出工具并恢复原来的右侧栏内容。

显示预设：

1. `显示顶层`：显示顶层丝印图形、`REF DES/SILKSCREEN_TOP` 位号、顶层器件焊盘、封装阻焊图形和焊盘阻焊开窗，并恢复正常顶视图。
2. `显示底层`：显示底层丝印图形、`REF DES/SILKSCREEN_BOTTOM` 位号、底层器件焊盘、封装阻焊图形和焊盘阻焊开窗，同时自动切换为底层镜像视图。
3. `显示双面`：同时显示 TOP、BOTTOM 两面的丝印位号、器件焊盘和阻焊相关层。
4. 勾选 `Place Bound` 时，额外显示对应面的 `PACKAGE GEOMETRY/PLACE_BOUND_*`。
5. 勾选 `显示过孔` 时，额外显示对应面的 `VIA CLASS/TOP` 或 `VIA CLASS/BOTTOM`。
6. 工具运行期间，菜单中的 `上一层`、`下一层` 只在顶层丝印和底层丝印之间切换；关闭工具或结束命令后恢复为正常铜层切换。

位号调整：

1. 默认处理工具运行期间在画布中选择的器件、位号文字或封装丝印线；勾选 `全部器件` 后无需选择，直接处理板内全部 Package/Mechanical 器件。
2. 勾选 `居中位号` 并点击 `应用` 后，工具只居中 `REF DES/SILKSCREEN_TOP/BOTTOM` 丝印位号。居中点优先取对应面的 `PACKAGE GEOMETRY/PLACE_BOUND_*` 几何中心；没有 Place Bound 时依次使用封装丝印、焊盘范围和器件范围中心。文字会先改为中心对齐，再读取文字实际包围盒，以文字外框中心对齐器件中心，横向和纵向均居中。
3. `水平旋转` 会把文字旋转设为 0 度，同时保留底层位号的镜像属性。
4. `字体` 填 `0` 表示保持现有 Text Block；填写正整数时统一位号使用的 Allegro Text Block。
5. `补齐缺失位号` 默认关闭；启用后会在器件对应 TOP/BOTTOM 面创建缺失的丝印位号，默认使用 Text Block 3。
6. 设置好居中、水平旋转、字体或补齐选项后，点击 `应用` 执行；一次批量处理作为一个 Allegro 事务提交，可以使用撤销恢复。

### 6.8 PCB 信息统计

`moka_info` 用于统计并显示：

1. 当前设计总管脚数
2. 当前未连线飞线数
3. 当日累计设计时长

### 6.9 Trace Analyzer

`moka_ta` 用于打开走线分析工具。

当前版本中，该工具用于对当前可见走线进行扫描和分析，并通过独立界面显示结果。

适合用于：

1. 检查当前可见走线
2. 做局部布线整理
3. 进行交互式分析与清理

### 6.10 走线等间距

打开方式：

1. 命令：`moka_spread_between_clines`
2. 短命令：`msbc`
3. 中文菜单：`Moka skill -> 走线等间距...`

操作流程：

1. 运行命令后，框选至少三根同层、相互平行的直线 Cline Seg。
2. 每条 Cline 只选择一段作为主移动段，不要选择整条 Cline。
3. 右键 `Done` 后，工具按主段中点在法线方向的投影自动排序。
4. 最外侧两段保持不动，中间段按中心线等间距移动。
5. 如果所选段两端还有同方向共线小段，工具会自动扩展到整条共线链。
6. 共线链最外端的唯一相邻直线沿原方向修剪或延伸，与移动后的主线重新求交。
7. 如果共线链到达走线端点、Pin/Via、分支、圆弧或 Fixed 邻段，该位置作为固定锚点；工具保留原对象，并用垂直于主线的短连接段接到平移后的共线链。

该工具的“等距”是中心线位置均匀分布，不会强制不同网络获得相同总长度。因为固定端点、保持全部折角角度和强制等长在一般几何中无法同时满足。

以下情况会整组拒绝且不修改数据库：

1. 少于三根有效 Cline Seg。
2. 走线不平行、不在同一层，或沿走线方向没有共同重叠区间。
3. 同一条 Cline 选择了多个主段。
4. 所选主段被 Fixed。
5. 移动后的主段退化为零长度，或唯一相邻折角臂与主段平行而无法获得唯一交点。

相邻段允许沿原直线穿过旧端点继续延伸；如果相邻段刚好收缩为零长度，工具会删除该段并让移动后的主段直接连接下一节点。固定锚点处新增的连接段只负责保持电气和几何连续，不会移动原分支、圆弧、Pin/Via 或 Fixed 邻段。工具故意忽略所有间距和物理冲突，可能产生在线 DRC。操作完成后应检查 DRC、线长、差分相位和实际可制造性。

## 7. 对齐工具说明

### 7.1 打开方式

可通过以下方式打开对齐工具：

1. 命令：`moka_align`
2. 别名：`aa`
3. 菜单：`Moka skill -> 对齐工具...`

### 7.2 对齐目标对象

对齐工具当前支持以下类型对象：

1. components
2. symbols
3. vias
4. groups
5. text
6. pins

### 7.3 对齐基准

具体规则如下：

1. 左对齐：所有对象左边界对齐到目标值
2. 右对齐：所有对象右边界对齐到目标值
3. 上对齐：所有对象上边界对齐到目标值
4. 下对齐：所有对象下边界对齐到目标值

### 7.4 Center X / Center Y

水平居中和垂直居中采用“对象集合 + 参考对象”的方式：

1. 先框选需要对齐的一组对象
2. 再单独选择一个参考对象
3. 所选对象的中心线对齐到参考对象中心线

规则如下：

1. `Center X`：对齐到参考对象的水平中心线
2. `Center Y`：对齐到参考对象的垂直中心线

### 7.5 水平分布 / 垂直分布

分布功能会根据对象中心点进行均匀分布：

1. `H Dist`：按 X 方向均匀分布
2. `V Dist`：按 Y 方向均匀分布

使用要求：

1. 至少选择 3 个有效对象

### 7.6 智能对齐

`moka_al_drag` 为智能对齐功能。

使用方式：

1. 通过框选方向判断意图
2. 系统根据拖拽方向自动推断对齐模式

适合快速执行上、下、左、右方向的直觉式对齐。

### 7.7 对齐到栅格

`moka_al_grid` 用于将对象吸附到设定栅格。

适合对分散对象做统一栅格归位。

### 7.8 栅格规则

对齐工具使用统一栅格参数 `_alg_grid_size`：

1. 栅格大于 `0` 时：对齐结果会按该栅格取整
2. 栅格等于 `0` 时：不启用栅格吸附，仅做几何对齐

启用栅格后，对齐和分布操作会将可移动对象自身的 `X/Y` 原点坐标吸附到设定格点；无独立 `xy` 原点的对象仍按其几何数据处理。

这条规则同时适用于：

1. 左右上下对齐
2. Center X / Center Y
3. 水平分布 / 垂直分布
4. 智能对齐
5. Snap To Grid

## 8. 换 Pin 工具说明

### 8.1 打开方式

可通过以下方式打开换 Pin 面板：

1. 命令：`moka_pin_swap`
2. 别名：`ps` 或 `mpinswap`
3. 菜单：`Moka skill -> 换 Pin...`

主面板采用 MiniStatus 形式嵌入 Allegro 右侧 `Options` 控制栏。换 Pin、日志和 Pinmap 控件按顺序紧凑纵向展开，换 Pin 记录列表使用加高滚动显示，不使用 Tab 控件或动态字段隐藏，避免 16.6 中出现空白容器和字段重叠。点击 `关闭`、右键 `Done` 或右键 `Cancel` 均可退出工具并恢复原来的右侧栏和 Find Filter；若当前环境无法加载 MiniStatus，则自动回退为靠右显示的紧凑浮动窗体。

### 8.2 交互式换 Pin

1. 点击 `开始换 Pin` 后选择一个器件。
2. 选择第一个 Pin，该 Pin 会单独高亮。
3. 选择同一器件内的第二个 Pin，工具强制交换两个 Pin 的网络。
4. 右侧栏中的 `Oops` 可清除当前第一引脚或撤销上一组交互操作；`完成` 提交当前事务，`取消操作` 回滚当前事务。

### 8.3 日志与导出

面板实时显示当前和已提交的换 Pin 信息，格式为：

```text
U1.1 3V3 -> U1.1 GND
```

`导出日志` 只导出换 Pin 前后的映射信息。导出成功后，待导出的已提交日志会被清空。

### 8.4 Pinmap

`导出 Pinmap` 根据器件 Pin 的本地物理坐标生成 Microsoft XML Spreadsheet 表格：

1. 每个器件使用一个以 RefDes 命名的工作表。
2. 引脚按照器件顶视图的实际物理分布排列。
3. 每个物理 Pin 对应一个方形单元格。
4. Pin 单元格只显示可编辑的网络名，Pin 号由单元格的物理位置确定。
5. 空物理位置保持空白。
6. BGA 器件通过 Pin 号的“字母行 + 数字列”及物理坐标一致性识别，四边表头显示真实球位行列。
7. 非 BGA 器件的真实 Pin 号只在其物理位置旁显示一次。完整 `2 x N` 双列阵列按 `左 Pin 号 | 左网络 | 右网络 | 右 Pin 号` 排列；完整 `N x 2` 双行阵列则按 `上 Pin 号 / 上网络 / 下网络 / 下 Pin 号` 排列。Pin 号与对应网络相邻并使用独立单元格，不再按四个方向展开。非完整阵列（例如 QFN100）仍沿封装外围显示 `1...100`，每个 Pin 号仅出现一次。
8. 默认 Pin 单元格使用 `0.9.5` 的浅绿色背景；勾选 `导出网络颜色` 后，具有 PCB 自定义网络颜色的 Pin 优先使用对应颜色。

`导入并应用` 会读取表格中的网络值，按工作表和单元格物理位置确定 Pin，然后执行批量换 Pin。任意一项失败时，整批操作会回滚。

### 8.5 Pinmap 导入约束

1. 文件必须保持 Microsoft XML Spreadsheet `.xml` 格式。
2. 工作表名称必须匹配已放置器件的 RefDes。
3. 不得插入、删除或移动布局行列。
4. Pin 单元格只能包含一行网络名，网络不能为空；未连接使用 `<UNCONNECTED>`。
5. 四边 Pin/球位表头只用于阅读，导入时按中间物理单元格位置确定 Pin。
6. 空白物理位置不得写入内容。
7. 同一器件的导入网络必须构成完整置换，不能遗漏单向映射。
8. 导入文件必须保留四边表头和中间物理布局。

## 9. Anti-Pad 工具说明

### 9.1 打开方式

可通过以下方式打开：

1. 命令：`moka_dp_antipad`
2. 兼容命令：`dp_antipad`
3. 别名：`mdpa`
4. 菜单：`Moka skill -> 反焊盘...`
5. Moka 主面板：`Anti-Pad`

主面板采用 MiniStatus 形式嵌入 Allegro 右侧 `Options` 控制栏。目标、几何、放置层、开关和尺寸参数按顺序纵向展开，应用、删除、完成、取消和关闭按钮位于底部。布局不使用 Tab 控件或动态字段隐藏，以兼容 16.6；点击 `关闭`、右键 `Done` 或右键 `Cancel` 均可退出并恢复原来的右侧栏和 Find Filter，MiniStatus 不可用时自动回退为靠右显示的紧凑浮动窗体。

### 9.2 推荐操作流程

1. 设置目标类型和几何方式。
2. 选择一个放置层，并设置外扩量、尺寸/最小直径；需要统一尺寸时勾选 `固定大小`，自动差分对模式还需设置最大配对距离。
3. 建议保持 `替换已有设置` 与 `操作前确认` 为勾选状态。
4. 点击 `选择并应用`。
5. 在画布中选择 Via、Pin、器件、Cline、Cline Seg、Shape 或 Group；不同目标模式对选择数量的要求见下文。
6. 确认高亮对象后应用。
7. 可继续选择其他对象；右键 `Oops` 撤销上一组，右键 `Done` 或面板 `完成` 提交整次操作。

### 9.3 目标模式

1. `单个对象`：为每个选中对象分别创建反焊盘。选中组件、Symbol 或 Group 时，会展开为其中的 Pin；其他对象保持原对象。
2. `自动差分对`：选择一个或多个 Via/Pin，按差分约束自动寻找同类型的另一成员对象，并为每对对象创建一组反焊盘。
3. `手动双对象`：一次必须正好选择两个 Via/Pin，不要求已经建立差分约束。
4. `整体包围`：把本次选中的多个对象合在一起，只创建一个圆形、椭圆形或矩形外包图形。适合器件区域、连接器 Pin 群、走线段或 Shape 区域。

自动差分配对按以下顺序查找：

1. 如果对象已经绑定 Moka 反焊盘 ID，优先查找具有同一 ID 的另一对象。
2. 否则读取 Allegro `DIFF_PAIR` 约束组。
3. 在另一成员网络中查找与来源同类型的 Via 或 Pin。
4. 选择不超过 `最大配对距离` 的最近对象。

自动配对只适用于 Via/Pin；Cline、Cline Seg、Shape 和区域对象应使用单对象或整体包围。

### 9.4 几何与尺寸

几何形状：

1. `现有反焊盘`：对 Via/Pin 读取所选 ETCH 层上的 Padstack `ANTI` 轮廓，再按外扩量生成 Keepout；没有可用 `ANTI` 图形时回退到最小矩形包络。
2. `原始轮廓`：Via/Pin 从开始选择时的活动 ETCH 层读取 `REGULAR` 图形，再复制到目标 Keepout 层；Cline/Cline Seg 使用圆形端帽读取实际线宽轮廓。外扩过程不主动修圆，因此原有直角保持直角，原有圆弧保持圆弧。
3. `圆形`：使用来源对象包围盒的外接圆，叠加外扩量。
4. `椭圆形`：文字名称由原“胶囊形”改为“椭圆形”，几何算法保持不变；单对象按包围盒长轴生成圆端外形，差分对/手动双对象按两个对象中心连线生成共享外形。
5. `矩形`：按来源对象包围盒向四周扩展。整体包围时使用所有对象的联合包围盒。

尺寸参数：

1. `外扩量`：在来源轮廓或包围几何之外增加的距离，可为 `0`，不可为负数。
2. `固定大小`：用于圆形、椭圆形和矩形。勾选后，尺寸值作为固定直径、固定宽度或固定宽高；该值必须大于 `0`。
3. `尺寸/最小直径`：未勾选固定大小时，限制圆形/椭圆形的最小宽度，并用于扩展过小的轮廓或矩形；填 `0` 表示不设下限。
4. `最大配对距离`：仅自动差分对模式使用，必须大于 `0`。

面板中的数值均使用当前 PCB 设计单位。工具会根据 mil、mm、inch 或 micron 初始化合理的默认值。

### 9.5 放置层与属性

1. 面板只选择一个 ETCH 层，例如 `TOP`、`L2_GND` 或 `BOTTOM`。
2. 实际图形创建在对应的 `ROUTE KEEPOUT/<layer>` 子类，不修改 ETCH Shape，也不创建 Shape void。
3. 每个 Keepout 固定写入布尔属性 `ROUTES_ALLOWED = TRUE` 与 `VIAS_ALLOWED = TRUE`。
4. 工具还写入字符串用户属性 `MOKA_AP_KEEP_ID`，用于来源关联、替换和删除。

### 9.6 替换、删除与撤销

1. 工具为来源对象和创建的 Route Keepout 写入同一个 `MOKA_AP_KEEP_ID`。
2. 勾选 `替换已有设置` 后，再次应用同一对象组会先删除旧 Keepout，再按当前参数创建新 Keepout。
3. `选择并删除` 可选择来源对象或 Moka 创建的 Route Keepout；只删除同 ID 的 Moka Keepout，不删除其他人工 Keepout。
4. 交互会话中的右键 `Oops` 只撤销上一组操作。
5. `取消操作` 或右键 `Cancel` 回滚本次会话全部修改。
6. `完成` 或右键 `Done` 会提交并关闭本次 SKILL 数据库事务；提交后的修改不会进入 Allegro 全局 Undo，无法再用全局 Undo 撤销。
7. 需要撤销时必须在提交前使用右键 `Oops` 或 `取消操作` / `Cancel`。

### 9.7 适用范围与限制

1. 该工具创建的是 `ROUTE KEEPOUT` 图形，不修改 Padstack 定义，也不修改现有铜皮边界。
2. `现有反焊盘` 模式只对 Via/Pin 有真实 Padstack `ANTI` ；其他对象没有 `ANTI` 图形时会使用矩形包络回退。
3. `原始轮廓` 更适合 Cline、Shape 和非圆形焊盘；圆形、椭圆形、矩形适合快速统一规则。
4. `整体包围 + 原始轮廓` 会使用凸包连接对象之间的空隙，再与包含圆弧信息的原始多边形执行合并，因此只生成一个连续反焊盘，同时保留外侧原始圆弧和轮廓；无法读取来源轮廓时回退为整体矩形包围。`整体包围 + 现有反焊盘` 仍不支持，请改用原始轮廓、圆形、椭圆形或矩形。
5. 自动差分模式依赖 Allegro 中已建立的 `DIFF_PAIR` 约束；没有约束时使用手动双对象模式。

## 10. 叠层 / 阻抗工具说明

### 10.1 打开方式

1. 命令：`moka_stackup_impedance`
2. 别名：`msi`
3. 菜单：`Moka skill -> 叠层 / 阻抗...`

### 10.2 导出工作簿

`导出表格` 会从当前设计生成 Microsoft XML Spreadsheet 工作簿。第一页按照参考叠层阻抗表的格式排版：

1. `A:E` 区域保存层名、材料、典型厚度（mil）、介电常数和损耗因子，铜层、介质、阻焊及标题使用与参考表一致的分类颜色；铜层的 Dielectric Constant 和 DF 单元格保持为空，只在介质和阻焊行显示这两个参数。
2. `H:N` 区域保存 ETCH 层和 Physical CSet 参数；`I1:N1` 最多显示 6 个名称以 `ohm` 结尾的 Physical CSet，例如 `50ohm`、`50OHM`、`50 OHM`。
3. 标题、表头、列宽、行高和总厚度公式参照 `RK_NVR_DEMO1_RK3588_LP4XD200P232SD8_V21_20211228_final_lint阻抗叠层.xlsx` 的第一页工作表。
4. 导出时读取 Constraint Manager 的 Physical CSet：普通线宽显示为 `3.8`，存在差分间距时显示为 `3.8->4.2`；某层的 `Line Width-Min` 为 `0` 时不导出该 CSet 的层参数，所有匹配 CSet 在该层均为 `0` 时 H 列也不显示该层；没有匹配的 Physical CSet 时阻抗表头和数据保持空白。
5. 隐藏的 `_MokaMeta` 工作表保存格式版本、设计单位、完整层类型和 Technology File 原始节点；第一页未显示的 Cadence 属性不会在往返过程中丢失。

### 10.3 导入与模板替换

1. `Replace Stackup` 控制是否用第一页 `A:E` 区域的层序和材料参数替换当前板叠层。
2. `Replace Impedance` 使用 `I1:N1` 的名称匹配 Physical CSet，匹配不区分 `ohm` 大小写；同名 CSet 已存在时更新，不存在时复制当前设计的 `DEFAULT` Physical CSet 后创建。
3. 单元格单值（如 `3.8`）写入该层的 `Line Width -> Min`；箭头值（如 `3.8->4.2`）同时把 `3.8` 写入 `Line Width -> Min`，把 `4.2` 写入 `Differential Pair -> Primary Gap`。
4. 空白单元格不覆盖该层原有或默认参数；表格只处理与 A 列 ETCH 层名匹配的行。
5. 导入本工具导出的工作簿时，隐藏元数据用于恢复表面层、层类型及未显示属性；外部同版式模板可以不含 `_MokaMeta`。
6. 校验通过后先生成局部 Technology File，再由 Allegro 批处理加载；可只勾选叠层或阻抗进行局部模板替换。
7. 对已有走线/铜皮的设计，Cadence 不允许删除或重排现有 ETCH 层。导入层数更多的模板时，工具会保留现有 ETCH 层名称和相对顺序，在其间插入新增层，并把模板层名映射到实际层名后应用阻抗参数。
8. 模板 ETCH 层数少于当前设计时会拒绝导入，因为无法安全删除已有布线层；导入后再次导出的表格会显示设计中实际保留的层名。
9. 外层采用固定映射：模板首层 `L1` 默认映射为 `TOP`；模板最后一层映射为 `BOTTOM`，例如 8 层模板为 `L8 -> BOTTOM`，6 层模板为 `L6 -> BOTTOM`。
10. 层映射只按 ETCH 层顺序，不按名称搜索：模板第 1 层对应 `TOP`，模板最后一层对应 `BOTTOM`，中间现有层依次对应模板第 2、第 3……层。新增位置使用模板中的内部层名；若与已保留层重名，则改用该位置的 `L序号` 或 `ETCH序号`，不再生成 `GND02_NEW2` 一类名称。
11. Solder Mask 按 Cadence 版本处理：16.6 导入时忽略表格中的上下 Solder Mask 行；17.4 及以上按 Cross-section 的 Design-defined Mask 结构创建 `SOLDERMASK_TOP` / `SOLDERMASK_BOTTOM`，层类型为 `Mask`、功能为 `SOLDER_MASK`，与界面 Add Layers → Mask → Design-defined Mask Layers 的创建结果一致。
12. 应用 Technology File 会触发 Allegro 数据库 reload，因此功能 UI 会自动关闭；工具会在 reload 前释放旧表单句柄，完成后可再次输入 `msi` 正常打开。
13. 所有导入的 ETCH 铜层统一创建为 `CONDUCTOR` 正片层；16.6 强制设置 `CDS_LAYER_NEGATIVE_ARTWORK=FALSE`，17.4 清除负片属性，不根据 GND/PWR 名称创建负片 Plane。

### 10.4 工作簿约束

1. 文件必须保持 Microsoft XML Spreadsheet `.xml` 格式；版式与参考 `.xlsx` 一致，但不能仅修改扩展名后直接导入 `.xlsx`。
2. 第一页的叠层表头必须位于 `A2:E2`，阻抗表头必须位于 `H1:N2`，不要插入或删除关键列。
3. 层名不得重复，厚度、介电常数和损耗因子必须是有效数值。
4. `I1:N1` 的非空标题必须以 `ohm` 结尾且不得重复；最多支持 6 个 Physical CSet，H 列显示对应 ETCH 层。
5. 参数单元格只允许正数线宽或 `正数线宽->正数间距`；箭头必须使用半角 `->`。
6. 建议保留 `_MokaMeta` 以获得完整无损往返；外部同版式模板可以不含该隐藏工作表。
7. 不再兼容旧版独立 `Stackup`、`Impedance`、`_MokaMeta` 三工作表格式；导入时第一页必须使用当前参考版式。
8. 工作簿在 Excel 中打开时，导入会使用共享只读方式读取；导出无法覆盖已打开文件时，会自动在同目录生成带时间戳的新文件，并在状态栏显示实际路径。完全独占锁定时需先保存或关闭文件。

## 13. 注意事项

1. `alias` 是命令别名，不是连续双击键盘直接触发。
2. `funckey` 是单键映射，可直接按键触发。
3. 对齐类命令默认按对象几何包围盒计算，不按文字丝印内容计算。
4. `Center X / Center Y` 需要额外选择参考对象。
5. 分布命令至少需要 3 个对象。
6. 栅格为 `0` 时，表示关闭对齐吸附。
7. 反焊盘工具创建 `ROUTE KEEPOUT/<layer>`，不直接修改 ETCH Shape 或 Padstack。
8. `ROUTES_ALLOWED` 与 `VIAS_ALLOWED` 会允许走线和过孔通过 Keepout。
9. 批量操作前建议保留 `操作前确认`，并检查高亮对象或配对是否正确。
10. 安装器按原文件编码保留 Allegro 环境文件，只添加或删除带标记的 Moka Skill 配置块，不删除其他扩展或通用菜单文件。
11. Moka 菜单通过 `axlUIMenuRegister` 注册，不再修改 `MENUPATH`、生成通用菜单副本或调用 `axlUIMenuLoad` 重载 Allegro 主菜单。
12. 叠层与介质信息通过 Cadence Technology File 接口读取和应用，导入前应保存重要设计版本并确认层名、层数和单位。
